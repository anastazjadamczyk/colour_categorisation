# colour categorisation scripts

The repository contains scripts that we used to categorise the colours chosen by participants into colour categories.


In our study (ref.) participants chose colours from an unrestricted colour range. Their choices were saved as RGB values and then converted into CIE LCh using the R studio farver package (Pedersen et al., 2024).

The thresholds were based on information found in previous studies and were further adjusted based on the
observations made upon visualisation of a large independent dataset with colour preference data (N = 8,302; Ouznadji et al., 2026).

colour_categorisation_script.R is the pre-registered script
colour_categorisation_script_updated.R is the updated version, with improved thershold values for the BLUE/PURPLE border.
